📰 NewsBlog — A Real-Time Social News Platform

A full-stack social news blogging platform where users can create posts, like, comment, follow, bookmark, and receive real-time notifications.
Built with React, Node.js, Express, MongoDB, Socket.IO, and TailwindCSS.

🚀 Features
⭐ Authentication & Users

Secure login/signup with JWT

Profile management (bio, image, username)

Follow/Unfollow system

Personalized feed based on following

⭐ Posts & Interactions

Create, edit, delete posts

Like/unlike posts

Comment system with real-time updates

Bookmark posts for later

Post categories + search

⭐ Real-Time Notifications

Powered by Socket.IO

Realtime notifications for:

Likes

Comments

Follows

Unfollows

Bell icon with unread count

Notification page with history

⭐ Responsive, Modern UI

Styled using TailwindCSS

Smooth transitions, clean card layout

Mobile friendly design

⭐ Backend Features

REST API with Express

MongoDB + Mongoose models

Protected routes with JWT middleware

Optimized queries for feed & notifications

Scalable folder structure

Frontend

React.js (Vite)

Redux for global state

React Router

TailwindCSS

Axios for API calls

Backend

Node.js

Express.js
